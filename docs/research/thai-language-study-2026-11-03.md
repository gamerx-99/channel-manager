# รายงานศึกษา: ปรับคุณภาพภาษาไทยของ Agent (ข้อความ UI และการแปล)

วันที่ 3 พ.ย. 2569 · ขอบเขต: ศึกษาและเสนอแนะเท่านั้น ยังไม่ได้แก้ระบบ ไม่ได้ติดตั้งอะไรเพิ่ม

> ข้อจำกัดที่ต้องบอกก่อน: การอ่านเอกสารไม่ได้ทำให้ Agent ถูกฝึกโมเดลใหม่ สิ่งที่ปรับได้จริงคือ
> (1) อภิธานศัพท์ของโปรเจกต์ที่ Agent ต้องอ่านทุกครั้ง (2) เทสต์ที่จับคำผิดบริบทอัตโนมัติ
> (3) ขั้นตอนให้คนตรวจ ข้อเสนอทั้งหมดในรายงานนี้อยู่บนสามทางนี้

## 3. เชื่อมกับ PyThaiNLP

ผมไม่มีบันทึกว่าเคยศึกษาเอกสาร PyThaiNLP ในงานก่อนหน้า (ไม่มีใน memory ของโปรเจกต์)
ส่วนนี้จึงอ้างจากเอกสารปัจจุบัน (pythainlp.org/dev-docs) เท่านั้น

| ความสามารถ | API | ใช้กับ hayhost ได้อย่างไร |
|---|---|---|
| คลังคำไทย / คำตามราชบัณฑิตฯ | `corpus.thai_words`, `corpus.thai_orst_words` | ตรวจว่าคำใน `th.ts` สะกดตรงคลังคำ |
| ตรวจตัวสะกด | `pythainlp.spell` | สคริปต์ตรวจ `th.ts` แบบออฟไลน์ (ไม่เข้าระบบจริง) |
| ความถี่คำ | `corpus.tnc`, `corpus.ttc`, `corpus.oscar` | เลือกคำที่คนใช้บ่อยกว่าเมื่อมีสองตัวเลือก |
| คำพ้อง / ความหมาย | `thai_synonyms`, `thai_wsd_dict`, WordNet | หาคำทางเลือก แต่ต้องให้คนตัดสินบริบท |
| ถอดอักษร | `transliterate`, `th_en_translit` | สะกดคำทับศัพท์ให้สม่ำเสมอ |

**ข้อจำกัด:** PyThaiNLP เป็น Python ส่วนระบบเราเป็น TypeScript ถ้าจะใช้ต้องเป็นสคริปต์แยก
และต้อง **ขออนุมัติก่อนติดตั้ง** — และมันจับได้แค่ตัวสะกด/คำที่มีอยู่ จับ "แปลผิดบริบท" ไม่ได้

## 4. ศัพท์เทคนิคตามบริบท

หลัก: ถามก่อนว่า "ผู้อ่านคือใคร" — เจ้าของโรงแรมเล็กไม่ใช่นักพัฒนา คำที่เขาเห็นบนจอต้องเป็นคำที่เขาใช้พูดจริง

| คำอังกฤษ | บริบท | ใช้ | ไม่ใช้ | เหตุผล |
|---|---|---|---|---|
| **Live** | เว็บโรงแรมเปิดให้คนเห็นแล้ว | "เปิดใช้งานแล้ว", "ออนไลน์แล้ว" | "สดแล้ว", "ไลฟ์" | "สด" ในไทยหมายถึงอาหาร/ถ่ายทอดสด |
| | ข้อมูลห้องว่างอัปเดตทันที | "ล่าสุด", "อัปเดตทันที" | "ข้อมูลสด", "แบบสด" | เหมือนข้างบน |
| | ถ่ายทอดสด | "ไลฟ์", "ถ่ายทอดสด" | – | ตรงความหมาย |
| **Deploy** | (นักพัฒนา) ขึ้นระบบจริง | "ขึ้นระบบ", "deploy" (ในเอกสารทีม) | "ดีพลอย" บนจอลูกค้า | ลูกค้าไม่ต้องเห็นคำนี้เลย |
| | ลูกค้ากดให้เว็บเปิด | "เผยแพร่เว็บไซต์", "เปิดเว็บไซต์" | "ปรับใช้" | "ปรับใช้" เป็นคำบัญญัติที่คนทั่วไปไม่พูด |
| **Host** | ธุรกิจ hayhost ดูแลเว็บให้ | "ดูแลเว็บไซต์ให้", "ฝากเว็บ" | "โฮสต์ให้" | คนไทยพูด "ฝากเว็บ" |
| | เจ้าของที่พัก (host แบบ Airbnb) | "เจ้าของที่พัก", "เจ้าบ้าน" | "โฮสต์" | ยกเว้นตลาดที่ชินกับ Airbnb |
| | ชื่อแบรนด์ | "hayhost" (คงตัวพิมพ์เล็ก) | "เฮย์โฮสต์" | ชื่อแบรนด์ไม่แปล |
| **Instance** | เซิร์ฟเวอร์/ระบบหนึ่งชุด (เอกสารทีม) | "instance", "ระบบชุดหนึ่ง" | "อินสแตนซ์" บนจอลูกค้า | ลูกค้าไม่เกี่ยว |
| | "an instance of a booking" | "รายการ", "ครั้ง" | "อินสแตนซ์ของการจอง" | แปลตามโครงสร้างอังกฤษ |
| **Property** | ที่พัก/โรงแรม | "ที่พัก" | "พร็อพเพอร์ตี้", "ทรัพย์สิน" | "ทรัพย์สิน" = assets; ตอนนี้ใช้ "ที่พัก" 58 ครั้งถูกแล้ว |
| | property ในโค้ด/CSS | (ไม่แปล อยู่ในโค้ด) | "คุณสมบัติ" บนจอ | ไม่ควรโผล่บนจอ |
| **Sync** | ปฏิทินกับ OTA | "ซิงค์", "อัปเดตปฏิทินให้ตรงกัน" | "ประสานเวลา" | "ซิงค์" เป็นคำที่ใช้กันจริงแล้ว |
| **Key / Grant** (สิทธิ์ชั่วคราว) | ให้ทีม hayhost เข้าช่วย | "สิทธิ์เข้าช่วยดูแล", "อนุญาตชั่วคราว" | "กุญแจ" | **ปัญหาจริงตอนนี้** – เจ้าของบอกว่าฟังไม่คุ้นหู |
| **Dashboard** | หน้าแรกหลังบ้าน | "ภาพรวม", "แดชบอร์ด" | "แผงควบคุม" | ใช้ได้ทั้งสองแบบ ขอให้เลือกแบบเดียว |

## 6. ข้อเสนอแนะ (เรียงตามผลต่อแรงที่ใช้)

1. **ทำอภิธานศัพท์ของโปรเจกต์** `docs/thai-glossary.md` จากตารางข้อ 4
   (คำอังกฤษ → บริบท → คำที่ใช้ → คำห้ามใช้ → เหตุผล) และใส่ใน `CLAUDE.md` ให้ Agent
   และ Codex ต้องอ่านทุกครั้งที่เขียนข้อความไทย — ไม่ต้องติดตั้งอะไร
2. **เทสต์จับคำต้องห้าม** (Vitest, ไม่ต้องเพิ่ม dependency): อ่าน `th.ts` แล้วล้มถ้าเจอคำในรายการห้าม
   เช่น "กุญแจ" ในบริบทสิทธิ์, "แบบสด", "ข้อมูลสด", "พร็อพเพอร์ตี้", "ดีพลอย", "อินสแตนซ์"
   และตรวจว่า key ใน `th.ts` กับ `en.ts` ตรงกันครบ
3. **ขั้นตอนตรวจโดยคน**: ข้อความไทยใหม่ทุกชุดแสดงเป็นตาราง "เดิม → ใหม่" ให้เจ้าของดูก่อน commit
   (สอดคล้องกับกฎ natural-thai-copy ที่มีอยู่แล้ว)
4. **แก้ข้อความที่พบในข้อ 5** เป็นชุดเดียว (หลังเจ้าของอนุมัติคำ)
5. *(ทางเลือก ต้องขออนุมัติติดตั้ง)* สคริปต์ Python แยกที่ใช้ PyThaiNLP `spell` + `thai_orst_words`
   ตรวจตัวสะกดใน `th.ts` เป็นครั้งคราว ไม่เข้า build จริง — คุ้มเมื่อข้อความเยอะขึ้น
6. *(ไม่แนะนำตอนนี้)* นำ corpus/พจนานุกรมมาฝังในระบบ — license ไม่ชัด, ไม่ช่วยเรื่องบริบท
