# 08 — Vintage Old Town

```
Design a one-page hotel website (landing page) for a heritage guesthouse in an old town of northern Thailand. Theme name: "Vintage Old Town".

MOOD
Retro Thai travel poster from the 1960s: faded print colours, grainy paper, stamped badges, tickets and postcards. Nostalgic, charming, full of stories.

SAMPLE HOTEL (use as placeholder content)
- Name: Rattana Guesthouse 1962 (รัตนา เกสต์เฮาส์ 1962)
- Intro: "Our grandmother's shophouse, open to travellers since 1962. Five rooms, original floor tiles, the same morning market outside."
- Address: Chong Kham, Mueang Mae Hong Son, Thailand

VISUAL STYLE
- Palette: faded mustard #D9A441, retro teal #2E7C7A, brick orange #C2562E, aged paper #F1E6CC, dark ink #2B2622.
- Fonts: headings "Chakra Petch" Bold, styled like vintage signage; accent labels in "Charm" (a Thai script-style font) for small handwritten notes; body "Sarabun".
- Paper grain texture, halftone dots on photo edges, stamp-style circular badges ("Since 1962"), and dashed ticket-perforation dividers. Photos have a slight warm film tone and white postcard borders.
- Buttons: brick orange, styled like a printed ticket, with notched corners.

LAYOUT SIGNATURE (make this theme recognisable)
- Hero: designed like a vintage travel poster. A photo sits inside a thick paper border, with the hotel name in large signage type above and a "Since 1962" stamp badge. The booking box is styled as a train ticket with a perforated edge.
- About: a postcard layout with a photo on the left, the intro as "handwritten" text on the right, and a stamp in the corner.
- Rooms: each room is a ticket-shaped card showing the room name as the "destination", "up to N guests" as "passengers", and the price as the "fare".
- Gallery: postcards scattered on a paper background with captions under each.
- Location: a vintage-style illustrated map placeholder with the address in a stamped label.

DATA RULES (this site is generated automatically from a channel manager; use ONLY these blocks)
- Hotel name, intro paragraph (2–3 sentences), address (district, province).
- Up to 8 photos. Each photo has a short caption and a category: exterior, room, view, common area, food.
- 1–4 room types. Each has a name, max guests, "from ฿X / night" and one photo.
- Booking widget: check-in/check-out dates, adults, children, and a "Check availability" button. Payment is by Thai PromptPay QR.
- Location: address and a map placeholder.
- Header: hotel name (text logo), section links (Rooms, Gallery, Location), a TH | EN language switch, and a "Book now" button.
- Footer: hotel name, address, small text "Booking powered by hayhost".
DO NOT include reviews, star ratings, testimonials, amenity icon lists, blog, restaurant menu, newsletter signup, social media feeds, owner phone/email/LINE, or OTA price comparisons. We have no data for these.

SCREENS
1. Desktop landing page, 1440px wide.
2. Mobile landing page, 390px wide, with a sticky bottom bar showing "from ฿950" and a "Check availability" button.
Thai text must render correctly. Keep text contrast at WCAG AA or better. Use realistic Mae Hong Son old-town photography placeholders.
```

## Follow-up prompt (same project) — booking flow
```
Using the exact same "Vintage Old Town" style, design the mobile booking flow (390px) as 4 screens:
1) Select room: available room types for the chosen dates, with the price per night and the total.
2) Guest details: full name, phone, email, nationality, and the number of adults/children.
3) Summary: dates, room, total price, and the hotel's cancellation note text.
4) Payment: a PromptPay QR code, the amount, a 15:00 countdown timer, "Upload payment slip", and a "Waiting for verification" state.
```
