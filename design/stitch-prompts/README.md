# Stitch prompts — hotel website themes (hayhost)

One file = one theme = one Stitch project. Paste the whole prompt block of ONE file into a NEW Stitch project.
Never put two themes in the same project, or the styles will blend.

Every prompt repeats the same DATA RULES block on purpose. Each theme must use only the data
the system actually stores, so every theme can be filled automatically from any hotel.

Order of use in Stitch:
1. Paste the prompt. You get the Desktop + Mobile landing page.
2. If you want the booking flow too, send the follow-up prompt at the bottom of each file in the SAME project.
